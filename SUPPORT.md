# Support

Thank you for using Collab Digital Twins (CDT)! We're here to help you get the most out of the project.

## 🆘 Getting Help (community)

Community support for the open-source project is provided on a best-effort basis:

- **Check the documentation**
  Review the [README](./README.md), the files under [`docs/`](./docs/), and the docs site at [collabdt.org](https://collabdt.org) before opening an issue.

- **Search existing issues**
  Look through [open and closed issues](../../issues) to see if your question has already been answered.

- **Open a new issue**
  If you can't find a solution, [open a new issue](../../issues/new). Please include:
  - A clear description of the problem
  - Steps to reproduce (if applicable)
  - Screenshots, logs, or error messages
  - Your environment (OS, Node.js version, browser, etc.)

- **Discussions**
  Use [GitHub Discussions](../../discussions) for general questions, ideas, and tips.

## 🏢 Commercial & hosted support

CDT is dual-licensed (see [Licensing](./README.md#licensing)). If you run CDT in production, embed it in a product, or need guaranteed response times, a **commercial license and support agreement** is available from Collab Digital Twins, with defined SLAs and direct assistance.

- Licensing and support enquiries: **[support@collabdt.org](mailto:support@collabdt.org)**
- General contact: **[info@collabdt.org](mailto:info@collabdt.org)**

## 🔒 Security issues

For security vulnerabilities, **do not** open a public issue. Follow the responsible-disclosure process in our [Security Policy](./SECURITY.md) and email **[support@collabdt.org](mailto:support@collabdt.org)**.

## ⏱ Response times (community)

Community response times are best-effort and not guaranteed:

- **Issues:** 2–5 business days
- **Pull requests:** 5–10 business days

Guaranteed response times are available under a commercial support agreement (see above).

## 🙌 Contributing

We welcome contributions! If you'd like to help fix a bug or add a feature, read the [Contributing Guide](./CONTRIBUTING.md). Note that all contributors sign the [Contributor License Agreement](./CLA.md).

Thank you for your patience and support. Together, we can make this project better!
